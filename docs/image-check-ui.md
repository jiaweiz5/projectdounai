# 图片核验界面

图片入口统一为“图片核验”，沿用文案页的红白配色、圆角卡片、胶囊导航与双栏布局。移动端纵向排列。

左侧支持选择、拖拽、粘贴图片、完整预览、更换和清空。右侧呈现等待、加载、失败、无法判断和实际模型结果；修改输入会清除旧结果。结果可下载为文本。

## 检测范围

- 图文一致性：图片与对应文案通过现有 `/api/analyze` 接口检测，图片上限 2 MB，文案上限 10,000 字；关闭额外报告生成。匹配分数不是造假概率。
- 原图比对：待核验图和同一画面的可信原图通过 `/api/analyze-layer4-reference` 比较，每张上限 12 MB。显示模型估计的改动可能性及差异区域数。
- 支持 JPG、PNG、WebP；不支持视频。现有后端不提供单张图片是否由 AI 生成的检测，界面明确说明此限制。
- 非完成状态、模型不可用或缺少有效标签时，不输出确定结论或概率。

原图接口本地默认连接 `http://127.0.0.1:8000`。远程后端仍要求 `BACKEND_SHARED_TOKEN`；不将后端内部错误内容返回浏览器。

## 验证

- TypeScript 与针对修改文件的 ESLint 检查通过。
- 本地浏览器上传项目测试图片 `case_085_reference.jpg`，同图原图比对真实请求成功：暂未发现明显改动，模型估计 12.6%，差异区域 0。
- 移除图片后旧结果清除；清空与模式切换正常。
- 检查 1440 像素桌面及 390 像素手机布局。
- 本轮未重新评估图文模型准确率，也未用 UI 调整改变模型算法。
