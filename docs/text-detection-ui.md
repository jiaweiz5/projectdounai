# 文案鉴别界面改版

默认先检测文案：粘贴正文 → 开始鉴别 → 右侧查看结果。配图核验与评论分析放在单独的切换入口。桌面使用双栏，窄屏上下排列。各入口保留独立输入状态。

## 视觉依据

- 交互布局参考用户提供的腾讯朱雀截图：顶部标题、检测类型切换、左侧编辑、右侧结果。
- 参考小红书公开的小程序设计指南 https://miniapp.xiaohongshu.com/doc/DC356923 的易用、一致、清晰、简洁原则。该指南不等同于网页版完整组件规范。
- 本项目采用红色 #FF2442、浅色背景、白色圆角卡片与胶囊按钮作为设计选择；不声称通过小红书官方认证，也不使用其官方标识。

## 实现与边界

- page.tsx：独立文案输入、20 字最小长度提示、10,000 字上限、UTF-8 TXT 导入、示例、快捷键、清空、超时/错误状态及文本报告下载。
- verifier.css：页面视觉与响应式规则。
- AdditionalChecks.tsx：从原主页保留配图、原图比对、评论 OCR、编辑和分析能力；只有所选入口的数据参与其请求。
- 中文为默认语言，保留英文切换；使用系统字体以避免启动依赖外部字体下载。
- 文案检测仍调用既有 /api/analyze，include_report=false，直接展示分类器结果，不增加生成式解释调用。
- 环形图表示模型对整篇文案的 AI 参与可能性，不是 AI 字数占比。没有添加句子高亮、混写比例或虚构分类能力。
- 推广倾向单独折叠展示，不合成为可信度。未检测、检测失败、模型拒判都不会显示伪造分数。
- 本次没有调整检测器、阈值、模型或数据集。

## 验证

- TypeScript 类型检查及改动 TS/TSX 文件 ESLint 检查。
- 浏览器检查桌面双栏、窄屏排列，实际请求本地检测接口并显示返回分数。
- 检查示例、短文本提示、编辑清除旧结果、清空、配图与评论入口。
- 配图/评论的模型性能不属于本次 UI 验证范围。
